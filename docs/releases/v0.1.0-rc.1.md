# v0.1.0-rc.1 — experimental Mac source prerelease

This prerelease scope is source code, build tools, manifests, tests and analysis
for Sega Rally Championship Revision B (`srallycb`) on macOS. It includes no ROMs,
extracted assets, generated game code or playable app. Build a personal local
app from verified ROMs you supply; it is ad-hoc signed for the build Mac's
architecture, not notarized or a universal distribution. Phone work is deferred.

Start with [Mac setup](../getting-started.md), then the
[build and validation guide](../segarally-build-validation.md) and
[player manual](../mac-player-manual.md). The
[architecture](../segarally-architecture.md) explains generated i960/TGP/68000
execution, native Model 2A devices, SCSP sound, SDL3 and Metal presentation.

## Included behavior

- Windowed play with keyboard and recognized SDL gamepads, analog steering and
  pedals, remappable controls, cabinet saves and paused Settings.
- Native sound, optional CRT presentation and Accurate textures, with display
  enhancements off by default on fresh preferences.
- Cabinet-input scripts, recording and exact same-executable offline replay.
- Reproducible import/generation/build/test/local-package workflow with pinned
  dependencies and retained upstream notices.

## Recorded validation and limits

The recorded candidate 006 checkpoint passes the ten-step Mac pipeline and all
eleven dedicated Mac CTests. Sound-on Metal captures preserve the known
20,000-frame Championship path, an 18,000-frame SHORT Practice Mountain path
and a 14,000-frame Practice Lakeside path. Championship clears Desert and Forest,
then retires near Mountain's finish. SHORT Practice Mountain finishes, reaches
name entry and the scoreboard, then returns to attract. Lakeside retires near
its finish. Exact executable replay checks the recorded execution, PCM hashes
and final saves; it is not an independent hardware comparison.

A measured playback-starvation mechanism is fixed with one device period of
additional buffering. A visible 7,200-frame captured check has no shortfalls or
drops and preserves native PCM. Broader listening confirmation, different audio
devices and sustained visible performance remain separate work. Saved-scene
pixel equality in Accurate textures mode does not establish every game frame.

**Full Championship completion and full-game fidelity are not established.**
Extended-precision floating point, exact physical timing, full MAME-machine
comparison and PCB validation remain open. A verified reference ROM inventory
is input readiness, not execution parity. This prerelease does not certify
arcade fidelity or guarantee a frame rate. The detailed
[status reference](../segarally-status.md) and [handoff](../../HANDOFF.md) retain
checkpoint identities, costs, failed attempts and evidence boundaries.

Useful feedback includes remaining course paths, controller menu/remapping and
neutral-resume behavior, and audio listening on additional devices. Follow
[CONTRIBUTING.md](../../CONTRIBUTING.md); do not attach game data or packaged apps.
